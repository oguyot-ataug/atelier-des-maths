menu_book Le cours

1

Un programme de flèches

Programmer
Un programme, c'est une suite d'instructions qu'on suit dans l'ordre, une par une. Chaque flèche fait avancer le robot d'une case.
Le robot va suivre le programme, flèche après flèche.

Avant de lancer : la classe lit le programme et prévoit où le robot s'arrête.

Règle
Pour aller au même endroit, il y a souvent plusieurs programmes possibles. Les programmes 1 et 2 arrivent tous les deux sur l'étoile.
2

Éviter les obstacles

Les murs

Le robot ne peut pas passer sur les murs gris : il faut les contourner.

Avant d'écrire le programme, on trace le chemin avec le doigt, puis on écrit une flèche pour chaque case.
3

Trouver l'erreur

Le robot va suivre le programme, flèche après flèche.

Ce programme a une erreur : où le robot se cogne-t-il ? Quelle flèche faut-il changer ?

Règle
Quand un programme ne marche pas, on cherche la flèche qui pose problème et on la corrige : c'est déboguer. Les informaticiens font cela tous les jours !
4

Le programme le plus court

Règle
Pour aller du robot à l'étoile, le programme le plus court n'a que les flèches nécessaires.

: 5 flèches. Impossible de faire plus court !

Au tableau ou dans la cour : un élève « robot », un élève « programmeur » qui montre les cartes-flèches. On peut aussi utiliser un petit robot de sol programmable.

history_edu Un peu d'histoire

history_edu Un peu d'histoire : les premiers programmes

En 1801, le Français Joseph-Marie Jacquard a inventé un métier à tisser qui suivait un programme écrit sur des cartes percées de trous : le métier tissait tout seul de très beaux dessins.

Plus tard, Ada Lovelace, une mathématicienne anglaise, a écrit vers 1843 ce que l'on considère comme le premier programme pour une machine à calculer. Aujourd'hui, les ordinateurs, les téléphones et les robots suivent tous des programmes !
