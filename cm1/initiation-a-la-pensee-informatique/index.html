menu_book Le cours

1

Coder un déplacement

Définition
Un programme est une suite d'instructions précises, écrites dans l'ordre, qu'un robot (ou un ordinateur) exécute les unes après les autres, sans jamais réfléchir à notre place.
Le code
Sur un quadrillage, on code un déplacement d'une case avec une flèche : ↑ vers le haut, ↓ vers le bas, ← vers la gauche, → vers la droite.
Programme : →→↑↑→

Lecture :

  • le robot avance de 2 cases vers la droite, monte de 2 cases, puis va d'une case à droite : il arrive sur l'étoile.
L'ordre des instructions est très important : ↑→ et →↑ n'arrivent au même endroit que s'il n'y a pas d'obstacle sur le chemin !
2

Répéter : la boucle

Règle
Quand une instruction se répète, on peut l'écrire plus court avec une boucle : « répéter 4 fois → » remplace →→→→.

On peut aussi répéter un groupe d'instructions :

  • « répéter 3 fois : →↑ » donne →↑→↑→↑ : le robot monte un escalier.
3

Trouver et corriger un bug

Définition
Un bug est une erreur dans un programme : le robot ne fait pas ce qu'on voulait. Déboguer, c'est trouver l'instruction fausse et la corriger.
Méthode
Pour trouver un bug, on exécute le programme pas à pas, avec le doigt sur le quadrillage, en vérifiant la position après chaque instruction.
4

D'autres programmes

Un programme de calcul est aussi une suite d'instructions :

  • « Choisis un nombre → ajoute 5 → multiplie par 2 ». Avec 3 : 3 + 5 = 8, puis 8 × 2 = 16.

Un programme de construction aussi :

  • « Trace un segment [AB] de 5 cm. Trace la droite perpendiculaire à [AB] passant par A… » : chaque étape doit être claire et dans le bon ordre.

edit Exercices et rédaction

Exercices

Exercice 1
Le robot part d'une case. Programme : →→↓←↓. De combien de cases s'est-il déplacé vers la droite ? vers le bas ?
Exercice 2
Écris ce programme plus court avec des boucles : ↑↑↑↑↑→→
Exercice 3
Que dessine le programme « répéter 4 fois : →→↓↓ » si le crayon trace le chemin ?
Exercice 4
Sam veut tracer un carré de 3 cases de côté : →→→↓↓↓←←↑↑↑. Le robot ne revient pas à son départ. Trouve le bug.
Exercice 5
Dans l'atelier de l'onglet Méthode, réussis les 4 défis. Pour le défi 3, utilise au plus 4 blocs.
Exercice 6
Écris un programme de calcul qui transforme 4 en 20, puis teste-le avec 10.

history_edu Un peu d'histoire : Ada Lovelace, la première programmeuse

En 1843, l'Anglaise Ada Lovelace écrit ce qu'on considère comme le premier programme informatique, pour une machine à calculer imaginée par son ami Charles Babbage. Elle avait compris qu'une machine pourrait un jour faire bien plus que des calculs : de la musique, des dessins…

Dans les années 1960, le chercheur Seymour Papert invente le langage Logo pour les enfants : ils programment une petite « tortue » qui se déplace et dessine. Scratch, que tu utiliseras peut-être au collège, en est un lointain héritier.
